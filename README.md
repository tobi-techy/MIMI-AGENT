# Mimi Agent

Mimi is a set of WhatsApp AI agents for FMCG distributors in Nigeria. They confirm deliveries with the shop, catch fake transfer alerts, and keep one shared, honest shop book.

Built during the Meta Global AI Hackathon (26 October to 5 November 2026). This repo holds only the work done during the event. Older Mimi work (the marketing website and the console prototype) lives elsewhere and isn't part of this submission.

All demo data is synthetic. The demo distributor, Coral Lane Trading, is fictional, and so is every shop, person, brand, phone number and account in it.

Setup and run instructions are coming as the build lands.
