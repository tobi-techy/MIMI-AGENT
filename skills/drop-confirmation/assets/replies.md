# Delivery receipt wording

Code writes the delivery receipt and every reply to it (send_delivery_receipt,
read_receipt_reply's shop_reply). Send those exactly. The pilot wording they follow:

- English: "{shop}, {rep} just dropped: {items}. Reply YES if correct, or tell me what's different."
- Pidgin: "{shop}, {rep} don drop: {items}. Reply YES if e correct, or tell me wetin no correct."
